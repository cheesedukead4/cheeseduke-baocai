資料備份／還原

啟用雲端同步後，所有人共用同一份資料；未啟用時資料只存在這台裝置。仍建議定期匯出 JSON 備份。

從舊版 HTML 搬資料：在舊版開啟「備份／還原 → 匯出 JSON 備份」，再於此處「匯入 JSON」，就會自動上傳到雲端。
